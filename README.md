# Tech-in

Forum diskusi teknologi (React + Redux Toolkit) memakai Dicoding Forum API.

```
npm install
npm run dev    # jalankan aplikasi
npm run lint   # ESLint (StandardJS)
npm run build
```

Struktur: `src/api` (REST), `src/states` (Redux store, slice & thunk), `src/components` & `src/pages` (UI), `src/hooks`, `src/utils`.
